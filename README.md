# صورة — Soura Product Studio

استوديو عربي لإنشاء عشر صور تسويقية من صورة منتج واحدة.

## المزايا
- رفع JPG وPNG وWebP حتى 10 MB.
- 10 زوايا تصوير، مع الحفاظ على شكل المنتج وألوانه.
- تصدير: 1080×1080، 1080×1350، 1080×1920، 1200×628.
- تنزيل الصور منفردة أو دمجها في صورة طويلة لصفحة الهبوط.
- عرض التقدم وإيقاف المجموعة بعد الصورة الحالية.

## التشغيل
الملف `worker/index.js` مستقل ويحتوي الواجهة العربية والخادم معًا؛ لا توجد خطوة بناء مطلوبة.

باستخدام Node.js 22 أو أحدث:

```sh
npx wrangler dev
npx wrangler secret put OPENAI_API_KEY
npx wrangler deploy
```

أضف المفتاح إلى أسرار الخادم فقط. النموذج الافتراضي `gpt-image-1.5`، ويمكن تغييره بمتغير `OPENAI_IMAGE_MODEL`.

**توليد الصور غير مفعّل قبل إضافة مفتاح OpenAI صالح برصيد API.** المعاينات داخل الموقع أمثلة توضيحية وليست صورًا مولّدة. لم يُختبر التوليد الحي دون مفتاح.

## ملاحظات النشر
GitHub يستضيف الكود. GitHub Pages وحده لا يشغّل خادم الذكاء الاصطناعي؛ انشر على Cloudflare Workers. قبل إتاحة خادم مدفوع للعامة أضف تسجيل دخول وحدود استخدام لحماية رصيد API.

تُرسل صورة المنتج إلى OpenAI عند الإنشاء. لا تُحفظ الصور على الخادم، وتُفقد النتائج عند إغلاق الصفحة. يحافظ التصدير على كامل الصورة بإضافة هوامش محايدة عند اختلاف النسبة عن المقاس المدعوم من النموذج.
